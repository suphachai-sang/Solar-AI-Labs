# Lab 4: Document to Timeline

## ภาษาไทย

### โจทย์

ใช้ AI ช่วยสร้างโปรแกรมที่ถอดข้อมูลจากไฟล์ `HW04-Input.pdf` และแสดงขั้นตอนและกิจกรรมเป็นภาพ timeline โดยใช้ `HW04-Output.jpg` เป็นตัวอย่างแนวทางการนำเสนอ

ข้อมูลต้องมาจากไฟล์ PDF 

### สิ่งที่ต้องส่ง

1. โปรแกรมที่รันได้ พร้อมวิธีติดตั้งและรัน
2. ผลลัพธ์ที่สร้างจาก PDF และคำอธิบายสั้น ๆ ว่าโปรแกรมถอดข้อมูลอย่างไร
3. Prompt หรือประวัติการใช้ AI ที่สำคัญ
4. ตัวอย่างอย่างน้อยหนึ่งรายการที่ตรวจเทียบกับ PDF พร้อมระบุข้อมูลที่อ่านไม่ชัดหรือข้อจำกัดที่พบ

---

## English

### Task

Use AI to help create a program that extracts information from `HW04-Input.pdf` and presents the steps and activities as a visual timeline, using `HW04-Output.jpg` as a reference for the presentation.

The information must come from the PDF.

### Submission

1. A working program with installation and run instructions.
2. The output generated from the PDF and a brief explanation of how the program extracts the information.
3. Key prompts or relevant AI conversation history.
4. At least one example checked against the PDF, noting any unclear information or limitations.
