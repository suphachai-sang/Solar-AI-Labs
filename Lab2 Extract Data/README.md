# Lab 4: Document Extraction and Requirements Summary

## ภาษาไทย

### โจทย์

ใช้ AI ช่วยพัฒนาโปรแกรมที่อ่านไฟล์ PowerPoint (`.pptx`) ในโฟลเดอร์นี้ โดยเขียน **function สำหรับดึงเนื้อหาจากเอกสารเป็น Markdown** แล้วส่ง Markdown ให้ LLM วิเคราะห์และสรุปว่าเอกสารมี requirement อะไรบ้าง


### สิ่งที่ต้องส่ง

1. ซอร์สโค้ด พร้อมวิธีติดตั้งและรัน
2. ไฟล์ Markdown ที่ดึงได้และไฟล์สรุป requirement
3. Prompt หรือประวัติการใช้ AI ที่สำคัญ โดยลบ credential ออก
4. ตัวอย่างการตรวจสอบผลสรุปเทียบกับสไลด์ต้นฉบับอย่างน้อย 1 ข้อ พร้อมข้อจำกัดที่พบ

---

## English

### Task

Use AI to help build a program that reads the PowerPoint (`.pptx`) file in this folder. Write **a function that extracts the document content into Markdown**, then send that Markdown to an LLM to identify and summarize the document's requirements.

The results must be traceable to the original slides. Choose your own tools, technologies, and interface. You have **10–20 minutes**.


### Submission

1. Source code with installation and run instructions.
2. The extracted Markdown and the requirements summary as separate files.
3. Key prompts or relevant AI conversation history, with credentials removed.
4. At least one example comparing the summary with its source slide, and any limitations found.
