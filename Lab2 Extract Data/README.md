# Lab 4: Document Extraction and Requirements Summary

## ภาษาไทย

### โจทย์

ใช้ AI ช่วยพัฒนาโปรแกรมที่อ่านไฟล์ PowerPoint (`.pptx`) สรุปว่าเอกสารมี requirement อะไรบ้าง


### สิ่งที่ต้องส่ง

1. ซอร์สโค้ด พร้อมวิธีติดตั้งและรัน
2. ไฟล์ Markdown ที่ดึงได้และไฟล์สรุป requirement
3. Prompt หรือประวัติการใช้ AI ที่สำคัญ โดยลบ credential ออก
4. ตัวอย่างการตรวจสอบผลสรุปเทียบกับสไลด์ต้นฉบับอย่างน้อย 1 ข้อ พร้อมข้อจำกัดที่พบ

---

## English

### Task

Use AI to help develop a program that reads a PowerPoint (`.pptx`) file and summarizes the requirements in the document.

### Submission

1. Source code with installation and run instructions.
2. The extracted Markdown file and the requirements summary.
3. Key prompts or relevant AI conversation history, with credentials removed.
4. At least one example comparing the summary with its source slide, along with any limitations found.
