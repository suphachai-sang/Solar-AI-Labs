# Lab 1: การประเมินการใช้ AI สร้าง Sales Dashboard

**เวลา:** 10–20 นาที  
**เครื่องมือ:** อนุญาตให้ใช้ AI  
**ข้อมูล:** ไฟล์ CSV ยอดขายทั้ง 3 ปีในโฟลเดอร์นี้

## 1. สิ่งที่ต้องการประเมินจากผู้สอบ

ให้ผู้สอบใช้ AI ช่วยสร้าง Sales Dashboard จากไฟล์ CSV หลายไฟล์ โดยประเมินทั้งกระบวนการและผลงาน

| สิ่งที่ประเมิน | พฤติกรรมที่คาดหวัง |
|---|---|
| การสื่อสารกับ AI | อธิบายเป้าหมาย โครงสร้างข้อมูล เงื่อนไข และผลลัพธ์ที่ต้องการได้ชัดเจน |
| ความเข้าใจข้อมูล | เข้าใจว่าแต่ละแถวเป็นรายการสินค้า และหนึ่งคำสั่งซื้ออาจมีหลายแถว |
| การพัฒนา Dashboard | ใช้ AI ช่วยสร้าง dashboard ที่นำเข้าข้อมูล แสดงผล และใช้งานได้จริง |
| การตรวจสอบความถูกต้อง | ตรวจตัวเลขสำคัญด้วยข้อมูลต้นทาง และพบข้อผิดพลาดจากการสรุปข้อมูล |
| การแก้ปัญหาร่วมกับ AI | วิเคราะห์ปัญหา ให้ข้อมูลเพิ่มเติมแก่ AI และปรับแก้จนได้ผลลัพธ์ที่ต้องการ |
| การตัดสินใจ | เลือกตัวชี้วัดและรูปแบบการแสดงผลที่ช่วยตอบคำถามทางธุรกิจได้ |

## 2. Feature ที่สามารถประยุกต์ทำได้ใน Dashboard

### ตัวอย่าง Feature ที่ผู้สอบอาจเลือกทำ

| Feature | รายละเอียด |
|---|---|
| รวมข้อมูลหลายไฟล์ | อ่านและรวมข้อมูล CSV ทั้ง 3 ปีเพื่อวิเคราะห์ร่วมกัน |
| KPI สรุปผล | แสดงยอดขายหลังหักส่วนลด กำไรขั้นต้น จำนวนออเดอร์ และมูลค่าเฉลี่ยต่อออเดอร์ |
| ตัวกรองข้อมูล | กรองตามปี ภูมิภาค พนักงานขาย และหมวดสินค้า โดยข้อมูลที่เกี่ยวข้องเปลี่ยนตาม |
| กราฟยอดขาย | แสดงแนวโน้มยอดขายตามเวลา และเปรียบเทียบยอดขายตามพนักงานหรือสินค้า |
| จัดการสถานะ | KPI ยอดขายหลักนับเฉพาะรายการ `Completed` และแสดงสถานะอื่นแยกได้ |
| นับออเดอร์ให้ถูกต้อง | นับ `order_id` แบบไม่ซ้ำ เนื่องจากหนึ่งออเดอร์อาจมีสินค้าหลายรายการ |

### ตัวอย่าง Feature เพิ่มเติม

| Feature | ตัวอย่าง |
|---|---|
| เปรียบเทียบช่วงเวลา | ยอดขายเทียบช่วงเดียวกันของปีก่อน พร้อมเปอร์เซ็นต์การเปลี่ยนแปลง |
| วิเคราะห์กำไร | เปรียบเทียบยอดขาย กำไร และอัตรากำไรตามสินค้า |
| เจาะรายละเอียด | คลิกภูมิภาคเพื่อดูจังหวัด พนักงานขาย หรือรายการที่เกี่ยวข้อง |
| ค้นหาความผิดปกติ | แสดงรายการที่มีส่วนลดสูงแต่กำไรต่ำหรือติดลบ |
| อัปโหลดไฟล์ | เลือก CSV หลายไฟล์ และแจ้งเมื่อคอลัมน์ที่จำเป็นหายไป |
| ถามข้อมูลด้วยภาษาธรรมชาติ | พิมพ์คำถามเกี่ยวกับยอดขาย แล้วแสดงคำตอบพร้อมตัวเลขอ้างอิง |

รายการข้างต้นเป็นตัวอย่างสำหรับผู้จัดสอบ ผู้สอบสามารถเลือก feature อื่นได้ตามความเหมาะสมของเวลา **10–20 นาที** โดยประเมินจากประโยชน์ ความถูกต้อง และการทำงานจริง ไม่จำเป็นต้องทำตามรายการทั้งหมด ส่วนการถามด้วยภาษาธรรมชาติเหมาะเป็นข้อโบนัสหรือใช้เมื่อเตรียมระบบเชื่อมต่อ AI ไว้แล้ว

## 3. เกณฑ์การให้คะแนน

| หัวข้อ | คะแนน | แนวทางพิจารณา |
|---|---:|---|
| ความถูกต้องของข้อมูลและตัวเลข | 40 | รวมไฟล์ถูกต้อง และคำนวณตัวเลขที่เลือกแสดงได้ตรงตามนิยามที่ระบุ เช่น สถานะที่นำมาคิดและการนับออเดอร์ไม่ซ้ำ |
| การทำงานของ Dashboard | 25 | เปิดใช้งานได้จริง และส่วนที่เลือกพัฒนาทำงานสอดคล้องกัน |
| Feature เพิ่มเติม | 20 | feature ที่ผู้สอบเลือกออกแบบช่วยให้วิเคราะห์ข้อมูลได้ ใช้งานได้จริง และแสดงผลถูกต้อง |
| การใช้ AI และการตรวจผลงาน | 15 | อธิบาย prompt ที่ใช้ วิธีตรวจคำตอบ และสิ่งที่แก้ไขหรือเหตุผลที่มั่นใจว่าผลลัพธ์ถูกต้อง |
| **รวม** | **100** | |

### สิ่งที่ให้ผู้สอบส่ง

1. Dashboard ที่รันได้และวิธีเปิดใช้งาน
2. Prompt หรือประวัติการใช้ AI
3. ตัวอย่างการตรวจสอบตัวเลขอย่างน้อย 1 รายการ เช่น เปรียบเทียบยอดบน dashboard กับผลรวมจากไฟล์ CSV ต้นทาง
