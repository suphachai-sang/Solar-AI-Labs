# Lab 1: Sales Dashboard

## ภาษาไทย

### โจทย์

ใช้ AI ช่วยสร้าง Sales Dashboard จากข้อมูลยอดขายจำลองในไฟล์ CSV ที่เตรียมไว้ 

### สิ่งที่ต้องส่ง

1. ผลงานที่สามารถเปิดใช้งานได้ พร้อมคำอธิบายวิธีรัน
2. Prompt หรือประวัติการใช้ AI ที่สำคัญ
3. คำอธิบายสั้น ๆ ว่าคุณตรวจสอบความถูกต้องของผลงานอย่างไร พร้อมตัวอย่างอย่างน้อย 1 รายการ

---

## English

### Task

Use AI to help create a Sales Dashboard from the provided CSV files containing simulated sales data. 


### Submission

1. A working solution with instructions for running it.
2. Key prompts or relevant AI conversation history.
3. A short explanation of how you verified your work, including at least one example.
